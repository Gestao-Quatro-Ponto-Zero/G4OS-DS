# Política de segurança

## Versões suportadas

Corrigimos vulnerabilidades na versão mais recente publicada no npm (`@g4os/ds`).

## Como relatar

**Não abra issue pública** para vulnerabilidades. Use o [relato privado do GitHub](https://github.com/Gestao-Quatro-Ponto-Zero/G4OS-DS/security/advisories/new) com:

- descrição do problema e impacto;
- passos para reproduzir (ou prova de conceito);
- versão afetada.

Respondemos em até 3 dias úteis e combinamos um prazo de correção e divulgação.
