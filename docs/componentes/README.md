# Componentes

A referência de cada componente (exemplo vivo, regras de uso e props) mora no showcase, gerado do código: `npm run showcase` → **Componentes**, **Gráficos**, **Dashboards**. O inventário por família está no [README](../../README.md#componentes).

Quando escolher cada um:

- Formulários: [padroes/formularios.md](../padroes/formularios.md)
- Tabelas, filtros, quadro: [padroes/tabelas-e-colecoes.md](../padroes/tabelas-e-colecoes.md), [padroes/pipelines.md](../padroes/pipelines.md)
- Drawer, modal, popover, menu: [padroes/superficies.md](../padroes/superficies.md)
- Toast, estados, erros: [padroes/feedback-e-estados.md](../padroes/feedback-e-estados.md)
- Gráficos e KPIs: [fundamentos/dados.md](../fundamentos/dados.md), [padroes/dashboards.md](../padroes/dashboards.md)
